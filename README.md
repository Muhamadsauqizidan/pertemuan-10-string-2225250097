## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Pastikan Python sudah terpasang.
3. Buka terminal di folder proyek.
4. Jalankan latihan:
   `python latihan/01_dasar_string.py`
5. Jalankan tugas utama:
   `python tugas/normalisasi_data_mahasiswa.py`
